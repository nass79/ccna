# Day 4

Durant cette vidéo, on a appris à utiliser la **CLI (Command-Line Interface)**, qui permet de configurer les appareils Cisco à l'aide de commandes :

**CLI :** Interface en ligne de commande utilisée pour configurer les routeurs et les switches Cisco.

**CISCO IOS :** Système d'exploitation utilisé sur les équipements réseau Cisco.

**USER EXEC MODE (`>`):** Mode qui permet d'accéder aux commandes de base.

**PRIVILEGED EXEC MODE (`#`):** Mode qui donne accès à des commandes avancées et à la configuration de l'appareil.

**GLOBAL CONFIGURATION MODE :** Mode qui permet de modifier la configuration générale de l'équipement.

**HOSTNAME :** Nom attribué à un équipement pour pouvoir l'identifier facilement sur le réseau.

On a appris à passer d'un mode à un autre avec des commandes comme `enable`, `disable`, `configure terminal` et `exit`.

On a également découvert des commandes utiles comme `show running-config`, qui permet d'afficher la configuration actuellement utilisée par l'appareil et plein d'autre qui permet de sécuriser un appareil cisco.

On a ensuite utilisé la CLI dans Cisco Packet Tracer pour apprendre à sécuriser un équipement Cisco.
