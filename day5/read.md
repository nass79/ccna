Durant cette vidéo, on a appris comment les **switches** font communiquer les appareils dans un réseau local :

**LAN :** Réseau local qui permet à plusieurs appareils de communiquer entre eux.

**TRAME ETHERNET :** Structure qui contient les données transmises sur un réseau Ethernet ainsi que des informations comme les adresses MAC source et destination.

**ADRESSE MAC :** Adresse physique utilisée pour identifier une interface réseau au niveau de la couche 2 du modèle OSI.

**HEXADECIMAL :** Système de numération en base 16, utilisé notamment pour représenter les adresses MAC.

**MAC ADDRESS TABLE :** Table dans laquelle le switch enregistre les adresses MAC et les ports associés aux appareils.

**MAC LEARNING :** Le switch apprend les adresses MAC sources des trames reçues pour savoir sur quel port se trouvent les appareils.

**FLOODING :** Lorsque le switch ne connaît pas le port correspondant à une adresse MAC de destination, il envoie la trame sur les autres ports du même réseau local, sauf sur le port de réception.

On a également appris qu'un switch peut transmettre une trame directement vers le port correspondant à l'adresse MAC de destination lorsqu'il connaît déjà cette adresse.

On a étudié le fonctionnement de la communication entre plusieurs appareils connectés à un ou plusieurs switches.
