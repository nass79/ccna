Durant cette vidéo, on a appris le <strong>modèle TCP/IP</strong> et les différentes couches qui permettent aux appareils de communiquer sur un réseau :

<strong>APPLICATION :</strong> Permet aux applications et aux services de communiquer sur le réseau.<br>

<strong>TRANSPORT :</strong> Permet de gérer la communication entre les appareils et de transporter les données.<br>

<strong>INTERNET :</strong> Permet notamment d'utiliser les adresses IP et de faire circuler les paquets entre les réseaux.<br>

<strong>NETWORK ACCESS :</strong> Permet aux appareils d'accéder au réseau et de transmettre les données sur le réseau local.<br>

<strong>PHYSIQUE :</strong> Permet de transmettre les données sous forme de signaux électriques, lumineux ou radio à travers un support physique.<br>

On a également vu comment les données sont encapsulées lorsqu'elles passent par les différentes couches :

<strong>Données → Segment → Paquet → Trame → Bits</strong>

On a ensuite utilisé Cisco Packet Tracer pour observer comment les données circulent entre les différents appareils d'un réseau.
